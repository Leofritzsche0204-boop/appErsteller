# Time is Money

Handy-App (iPhone + Android), die Preise in Arbeitszeit umrechnet.
Gebaut mit Expo / React Native + TypeScript, Backend später mit Supabase.

## App starten (Windows)

1. Einmalig: `npm install`
2. `npx expo start`
3. QR-Code mit der App **Expo Go** scannen (Android: in Expo Go, iPhone: mit der Kamera).

Handy und PC müssen im selben WLAN sein. Klappt das nicht: `npx expo start --tunnel`.

## Prüfen

```bash
npx tsc --noEmit   # Typen prüfen
```
